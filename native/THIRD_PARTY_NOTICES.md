# Native implementation provenance

The Swift helper, AX policies, protocol, secure-capture checks, original vector blue-whale cursor decoration, cancellation machinery, and disposable AppKit fixture are newly implemented for this project. No Codex source, text, screenshots, icons, or proprietary artwork is included.

## Optional private event-routing recipe

`SkyLight.swift` adapts the documented private symbol names, exact PID/window event fields, and macOS 27 window-local coordinate convention from the following MIT-licensed trycua/cua source. The Swift policy and control flow are original. This is an optional, disabled-by-default private API route, not an Apple-supported API. The helper never falls back to global HID input in preserve mode. Private authentication-envelope extraction via undocumented object-layout offsets, opaque focus/defocus records, duplicate public/private delivery, and off-window Chromium primer clicks are deliberately excluded.

Audited immutable source revision: `09ab2d0d5f1f64e2ff1a37192484921505ff7114` (the GitHub path-history API identifies this as the most recent commit touching both files). Initial research inspected moving `main`; the immutable versions below were subsequently re-fetched and their symbol signatures, MIT/SPDX headers, event fields, and coordinate contract checked before finalizing this implementation. This pins the audited reference, not an inferred historical checkout.
